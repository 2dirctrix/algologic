# League of AlgoLand

실시간 경쟁 알고리즘 프로그래밍 게임 플랫폼

## 프로젝트 개요

알고리즘 문제 해결과 경쟁 게임 요소를 결합한 멀티플레이어 플랫폼.

플레이어들은 실제 온라인 게임과 유사한 시스템을 제공하는 플랫폼에서 재미있는 알고리즘 학습이 가능하도록 하는 서비스.

게임 방에 참여하여 밴/픽/구매 단계를 거치고, 아이템과 스펠로 전략적 재미를 더한 실시간 코딩 대결을 경험할 수 있다.

본인 전적 기반 통계 서비스 제공을 통해 자신의 알고리즘 풀이 실력을 확인할 수 있다.

## 주요 기능

### 인증 및 사용자 관리
- 카카오 OAuth 연동을 통한 간편 로그인
- 언어 선호도 설정이 포함된 사용자 프로필 설정
- httpOnly 쿠키를 사용한 안전한 JWT 인증
- 브론즈부터 챌린저까지의 플레이어 티어 시스템

### 메인 대시보드
- 라이브 게임 배너 및 실시간 표시기
- 필터링 및 검색 기능이 있는 방 목록 조회
- 플레이어 랭킹 및 통계
- 히트맵 시각화를 통한 개인 활동 추적

### 게임 생성 및 관리
- 설정 가능한 커스텀 방 생성
- 다양한 프로그래밍 언어 지원
- 플레이어 수 커스터마이징 (2-8명)
- 방 공개/비공개 설정

### 경쟁 게임플레이
- **밴 단계**: 전략적 알고리즘 제외
- **픽 단계**: 도전할 알고리즘 선택
- **구매 단계**: 아이템 및 스펠 획득
- **플레이 단계**: Monaco Editor를 사용한 실시간 코딩
- **결과 단계**: 포괄적인 경기 분석

### 실시간 기능
- WebSocket 기반 실시간 통신
- WebRTC 연동을 통한 향상된 연결성
- 경기 중 실시간 채팅 시스템
- 실시간 플레이어 상태 업데이트

### 게임 강화 도구
- **아이템**: 게임플레이에 영향을 주는 특수 능력
- **스펠**: 경쟁에서 우위를 점하는 전략적 도구
- **가상 키보드**: 접근성 지원
- **사운드 이펙트**: 몰입감 있는 오디오 경험

## 프로젝트 구조

```
fe/
├── src/
│   ├── pages/                    # 메인 애플리케이션 페이지
│   │   ├── auth/                 # 인증 페이지
│   │   ├── main/                 # 대시보드 및 메인 콘텐츠
│   │   ├── game/                 # 인게임 관련 페이지
│   │   └── common/               # 지역 공통 컴포넌트
│   ├── components/               # 전역 공통 컴포넌트
│   ├── composables/              # Vue 컴포지션 함수
│   ├── stores/                   # Pinia 상태 관리
│   ├── router/                   # Vue Router 설정
│   ├── api/                      # API 서비스 및 유틸리티
│   ├── assets/                   # 이미지 및 스타일 리소스
│   ├── game/                     # 인게임 전용 로직 및 리소스
│   ├── websocket/                # WebSocket STOMP 서비스
│   └── utils/                    # 유틸리티
├── public/                       # 사운드 리소스
└── package.json                  # 의존성 및 스크립트
```

## 시작하기

### 사전 요구사항
- Node.js (v16 이상)
- npm 패키지 매니저

### 설치 및 실행

1. **저장소 클론**
   ```bash
   git clone <repository-url>
   cd c204-fe
   ```

2. **프론트엔드 디렉토리로 이동**
   ```bash
   cd fe
   ```

3. **의존성 설치**
   ```bash
   npm install
   ```

4. **환경 변수 설정**
   ```bash
   # /fe 디렉토리에 .env 파일 생성
   # 미공개
   ```

5. **개발 서버 실행**
   ```bash
   npm run dev
   ```
   `http://localhost:3000` 접속

### 사용 가능한 스크립트

| 명령어 | 설명 |
|--------|------|
| `npm run dev` | 개발 서버 시작 |
| `npm run build` | 프로덕션 빌드 |
| `npm run preview` | 프로덕션 빌드 미리보기 |
| `npm run lint` | 코드 린트 및 자동 수정 |
| `npm run format` | Prettier로 코드 포맷팅 |

## 아키텍처

### 실시간 통신 아키텍처
- WebSocket 연결을 통한 인게임 제어권한 서버 위임
- STOMP 프로토콜을 사용한 구조화된 메시징 (영상 및 실시간 타이핑 공유 데이터 채널)
- WebRTC 통합으로 향상된 연결성
- 사운드 알림이 포함된 실시간 채팅

### 상태 관리
- Pinia를 사용한 중앙집중식 상태 관리
- localStorage를 통한 상태 지속성
- 컴포넌트 간 반응형 데이터 공유

### 보안
- httpOnly 쿠키 기반 JWT 인증
- 라우터 가드를 통한 접근 제어 및 인증 인가 관리
- API 요청 인터셉터를 통한 토큰 관리

## API 통합

| 통신 방식 | 엔드포인트 | 용도 |
|-----------|----------|------|
| REST API | `/api/*` | 기본 CRUD 작업 |
| WebSocket | `/ws` | 실시간 게임 상태 |
| WebRTC | LiveKit | P2P 통신 |
